# Markdown 预览字体

使用 [霞鹜文楷 Lite](https://github.com/lxgw/LxgwWenKai-Lite) Regular，按 SIL Open Font License 1.1 分发，完整授权及版权声明见 [OFL.txt](OFL.txt)。

`LXGWWenKaiLite-Regular.woff2` 由上游 `fonts/TTF/LXGWWenKaiLite-Regular.ttf` 使用 FontTools 转换，未修改字形。仅作为应用内 Web 字体使用，随应用打包，无需联网或安装系统字体。

仅 Markdown 文档预览使用文楷；界面控件沿用系统字体，代码块沿用等宽字体。未覆盖的字符由系统字体回退。
