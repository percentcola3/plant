# 项目网页与 AI 文本引用

项目顶部统一显示文件和网页标签。点击「＋」直接创建独立空白网页标签，在页内地址栏输入 URL 后按 Enter 访问；空白页提供常用文档站点快捷入口。文件标签切换保留未保存草稿，关闭时确认丢弃。标签支持自适应宽度、横向滚动、拖动排序和右键关闭左侧、右侧、其他或全部标签。地址栏未提交内容按网页标签保留。

网页使用原生 Electron WebContentsView，用户自行登录。网页列表在本次应用运行期间保留，关闭项目或应用会释放网页；登录 Cookie 按工作区和项目隔离并保存在本机。

## 转为 HTML 设计稿

网页加载完成后，点击地址栏右侧的「转为设计稿」，将当前已加载的页面结构和样式复制为 HTML，保存到当前项目的 `网页设计稿/` 目录。每次生成独立文件，不覆盖原稿，原网页标签继续保留。

保存完成后自动打开 HTML 预览，并使用原网页的画布尺寸。可以通过现有「修改元素」调整文字、颜色、间距和尺寸，通过「源码」编辑 HTML，或选中元素后让 AI 修改。如果生成期间切换了网页或项目，只提示保存位置，不抢占当前页面。

- 复制当前加载状态，不自动登录、点击、滚动或抓取其他页面，也不调用模型。
- 保留常见 DOM、计算样式、图片及 SVG；网页的脚本、表单提交和链接跳转行为不会带入设计稿。
- 这是静态设计稿，布局以捕获时尺寸为准；动态交互、未加载内容、跨域嵌入页面等不能保证还原。无法复制的内容会提示。
- 图片等远程资源可能仍需要网络或原站权限，不保证离线可用。
- 网页在捕获时跳转、关闭或超出大小限制会报错，不保存不完整文件。保存路径在主进程校验，只能写入该工作区的当前项目目录。

## 对话行为

- `@` →「已打开网页」可以显式引用当前项目的一个或多个网页。
- 空白新标签不出现在 @ 列表中，也不自动引用。
- 没有显式网页引用时，使用当前激活网页；输入框上方显示可取消的「当前网页」标签。
- 切回项目文件、关闭网页或离开项目后，不再自动附带该网页。
- 发送时读取页面的当前文本；读取失败保留草稿并提示，不静默发送缺失的上下文。
- 优先读取可见 main / article / role=main，回退到 body.innerText。不会上传完整 DOM、脚本、Cookie、表单密码或图片。
- 每页最多 60,000 字符，每次最多 5 页、120,000 字符。截断会在界面和提供给 AI 的快照中注明。正文包含标题、URL 和读取时间，被明确标记为参考资料。
- 网页快照进入共用的对话文本提交路径，Claude / DCC / Peeka 使用相同的内容，不依赖 MCP。

## 边界

不自动点击、登录、滚动、翻页或抓取跨域 iframe。只读取已加载文字；Canvas、图片文字不在本版范围。OAuth 弹窗采用独立沙箱子窗口，其页面不自动加入 AI 上下文；普通新标签链接进入当前项目网页列表。

远程网页没有应用 preload 或 Node 权限。视图权限默认拒绝，API 只接受宿主主 frame 请求，每次读取校验窗口及项目归属。原生网页区域在应用弹窗和菜单出现时隐藏，关闭后恢复。

## 验证

已通过文本提取、URL 校验、项目隔离、跳转一致性、关闭释放、当前网页与显式引用状态测试；构建通过。未启动 GUI，真实网站登录、原生视图位置和第三方 OAuth 兼容性需要实际使用时验证。

设计稿新增验证覆盖 DOM/样式提取、伪元素、图片和 Canvas、脚本与表单清理、捕获限额、跳转和关闭、重复捕获、项目路径与符号链接边界，以及原有 HTML inspector 注入和编辑链路。未启动桌面应用，真实网站的视觉还原程度尚未做人工验证。类型检查与修改前的既有错误保持一致。
