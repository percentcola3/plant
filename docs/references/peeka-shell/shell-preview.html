    剪页插件

    在 Chrome 扩展页加载本地插件后，可从任意网页采集内容保存到本工作区剪页库。

    插件已就位 v0.3.0

    位置：/Users/didi/Documents/workspace-extension

    在 Chrome 中加载

    • 打开 chrome://extensions，右上角打开「开发者模式」
    • 点击「加载已解压的扩展程序」
    • 选择上一步中的目录

    完成

    回到任意网页 → 点工具栏的插件图标 → 选取内容 → 保存到剪页库工作区。

    项目结构

    控制各角色项目里 App 扫描哪个目录。改了之后当前项目会自动重扫。

    📁 PM 工作目录默认位置

    新建 PM 工作目录时的默认父目录。绝对路径。默认 ~/Documents/WorkSpace。

    🎨 UI 项目

    路径硬编码在 App 里（styles/<主题组>/、components/、outputs/、assets/icons/）。这是「保护壳」哲学的一部分——偏向约定而非配置，不自适应。如果你的 UI 项目结构不同，建议把它对齐到约定（或在 CLAUDE.md / 知识库里记录映射，由 AI 在生成时遵守）。
