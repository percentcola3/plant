# HeroUI v3 设计流程

1. 读取项目上下文，定位已关联的本模板；缺失时不要假定其存在。
2. 阅读 `AI_USAGE.md`、`design-guide.md` 和团队主题，再检索相关官方 Token 或 CSS。
3. 确认业务任务、目标框架和依赖版本。生成布局前选择组件、信息层级与交互状态。
4. React 项目使用匹配版本的官方 API；HTML 原型将必要 Token 转为本地样式，不直接执行官方源码。
5. 保持颜色、字号、圆角、间距一致，覆盖空、加载、错误、禁用和键盘焦点状态。
6. 在预览中检查层级、溢出、窄屏表现；列出资产来源及与官方组件的差异。
